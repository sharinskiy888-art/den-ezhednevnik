## Windows (ваш компьютер, проверка в своей сети)
- Обычный установщик `den-setup-102.exe`: «Далее» → email и пароль администратора → готово.
- Сервер запускается сам при включении компьютера и перезапускается при сбое.
- **Наружу закрыт**: брандмауэр пускает только из своей сети («Частная»). Из интернета — нет.
- Секрет и база доступны только системе и администраторам.
- Обновление = запустить новый установщик: сам остановит сервер, сделает копию, запустит новую версию. Откат = установщик прежней версии, данные на месте.

## VPS (для монтажников с мобильным интернетом)
- Одна команда ставит сервер, nginx и HTTPS (Let's Encrypt, продлевается сам).
- Обновление с копией перед ним; если новая версия не отвечает — сервер **сам возвращается** на прежнюю.
- Откат версии и возврат данных из копии — по одной команде.
- Пошаговая инструкция: `deploy/README.md` в ветке.

## Копии
Раз в сутки база + все фото (14 последних) и перед каждым обновлением. Возврат: `admin restore <копия>` (текущее состояние сначала само сохраняется).
