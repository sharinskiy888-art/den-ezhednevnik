# Установка сервера «День»

Три варианта. Данные в обоих хранятся только у вас, без чужого облака.

## 1. Компьютер с Windows (для проверки в своей сети)
1. Скачайте `den-setup-<версия>.exe` (собирается автоматически: GitHub → Actions → «Install test» → раздел Artifacts → `den-setup`).
2. Запустите и нажмите «Далее». На странице «Администратор» введите свой email и пароль (не короче 8 символов).
3. Готово: сервер запускается сам при каждом включении компьютера. На рабочем столе — ярлык «День (сервер)».
   - Он открыт **только для вашей домашней или рабочей сети**: из интернета к нему не подключиться (так требует правило безопасности для Windows 10).
   - Сеть Wi-Fi в Windows должна быть «Частная» (Параметры → Сеть → свойства сети). В «Общедоступной» сети (кафе, гостиница) сервер закрыт и для соседей по сети — это нарочно.
   - Проверять — **в браузере на этом же компьютере** (ярлык открывает `http://localhost:8787`). С телефона по Wi-Fi адрес `http://<адрес компьютера>:8787` откроется, но без HTTPS (защищённого соединения) браузер телефона запрещает приложению нужные функции (номера записей, PIN, камеру, установку значком) — для телефонов нужен вариант 2.
4. **Команды администратора** (добавить человека, сверка, копии) — в «Командной строке» от имени администратора:
   ```
   cd "C:\Program Files\Den"
   den-server.exe admin users
   den-server.exe admin add ivan@mail.ru -        (пароль спросит, не показывая на экране)
   den-server.exe admin reconcile
   ```
5. **Обновление** — запустите установщик новой версии. Он сам остановит сервер, сделает копию базы и запустит новую версию. **Откат** — запустите установщик прежней версии: данные сохранятся.
6. **Удаление** — «Параметры → Приложения → День — сервер». Данные остаются в `C:\ProgramData\Den\data`, файл настроек — `C:\Program Files\Den\den.env` (при повторной установке всё подхватится, вход у людей не слетит).

## 2. Арендованный сервер VPS в России (для монтажников с мобильным интернетом)
Нужно: VPS с Ubuntu 22.04 или 24.04 (1 ядро, 1 ГБ памяти хватает, процессор x86 или ARM) и домен (например, `den.vashsait.ru`), направленный на адрес VPS.
GitHub серверу не нужен: всё ставится из одного архива `den-server-<версия>.tar.gz` (GitHub → Actions → «Install test» → Artifacts → `den-server-linux`, или собрать `bash deploy/linux/make_release.sh`). Внутри — программа и все библиотеки, из интернета берутся только nginx и сертификат.
```
scp den-server-104.tar.gz root@адрес-VPS:          # со своего компьютера
tar xzf den-server-104.tar.gz && cd den-server-104 # дальше — на VPS
sudo bash deploy/linux/install.sh --domain den.vashsait.ru --email вы@почта.ru
sudo bash deploy/linux/admin.sh add вы@почта.ru - admin      # пароль спросит, не показывая
```
Сертификат HTTPS (Let's Encrypt) получается и продлевается сам.

| Что | Команда |
|---|---|
| Обновить (после `git pull`) | `sudo bash deploy/linux/update.sh` — копия базы, новая версия; если она не отвечает, сервер сам вернётся на прежнюю |
| Откатить на прежнюю версию | `sudo bash deploy/linux/rollback.sh` (каждый запуск — на шаг назад; список версий — `--list`) |
| Список копий / вернуть данные из копии | `sudo bash deploy/linux/admin.sh backups` / `sudo bash deploy/linux/admin.sh restore den-….db` |
| Журнал сервера | `sudo journalctl -u den -n 100` |

## 3. Модуль АК-Сервера (День-CRM)
1. Скачайте `AK-Crm-Modul-1.0.<версия>.zip` (GitHub → Actions → «Install test» → Artifacts → `ak-crm-module`).
2. В АК-Сервере: «Установить программу из файла» → выберите этот zip. Плитка «День-CRM» станет зелёной.
3. Вход, сотрудники, роли, копии и обновления — в АК-Сервере. Свой администратор, пароли и `den.env` не нужны.
   - Владелец и управляющий — руководители раздела «Клиенты», «только просмотр» видит всё без правок, остальные — монтажники (видят только свои заявки).

## Переезд на другой сервер (VPS → VPS или компьютер → VPS)
1. На старом: `sudo bash deploy/linux/admin.sh backup` (Windows: `den-server.exe admin backup`) — появятся `den-….db` и `files-….zip` в папке копий.
2. На новом поставить «День» (раздел 2), затем скопировать эти два файла в `/var/lib/den/backups/` (владелец `den`) и `/etc/den/den.env` со старого (права прежние: `sudo chown root:den /etc/den/den.env && sudo chmod 640 /etc/den/den.env`, затем `sudo systemctl restart den`) — тогда людям не придётся входить заново.
3. `sudo bash deploy/linux/admin.sh restore den-….db` — задачи, поручения, CRM и фото на месте. Направить домен на новый адрес.

## Копии
- Сами: раз в сутки база и все фото (хранятся 14 последних), плюс перед каждым обновлением.
- Где: Windows — `C:\ProgramData\Den\data\backups`, VPS — `/var/lib/den/backups`.
- Совет: раз в неделю копируйте папку `backups` на флешку или в другое место.

## Секреты
`den.env` (секрет подписи входа) создаётся при установке со случайным значением. Его не нужно знать, копировать в чаты и архивы.
Windows — `C:\Program Files\Den\den.env` (читают только администраторы и система), VPS — `/etc/den/den.env`.
